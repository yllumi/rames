# 4.3 Lapisan Bisnis — `app/library/`

> Bagian dari [dokumentasi arsitektur](../ARCHITECTURE.md) · Spesifikasi: [SPECS.md](../SPECS.md) · Panduan operasional: [DETAILS.md](../../DETAILS.md)

Semua logika bisnis ada di sini (controller tidak boleh berisi logika). Modul:

| Modul | Kelas | Peran |
|---|---|---|
| **Storage** | `SqliteDatabase` | Handle PDO SQLite tunggal (per berkas, per proses, §5.19): PRAGMA `journal_mode=WAL`/`synchronous=NORMAL`/`foreign_keys=ON`/`busy_timeout=5000`, transaksi `BEGIN IMMEDIATE` re-entrant (`transaction()`), `snapshot()` (`VACUUM INTO`), `integrityCheck()` (`PRAGMA integrity_check`), migrasi otomatis sekali per proses, impor legacy otomatis saat koneksi pertama (`maybeImportLegacy()`, best-effort), kunci cache handle = **identitas berkas** (`realpath#dev:ino`) sehingga berkas yang di-restore dibuka ulang; `reset()` untuk tes |
| | `SqliteStore` | API identik `JsonStore` (`path()`/`read()`/`write()`/`update()`) di atas SQLite: kolom `data` = dokumen JSON (**sumber kebenaran**) + kolom turunan terindeks + `ord` (urutan list); satu store = 1..N koleksi (list bila `idField` terisi, map via `path`). `update()` = satu transaksi (baca→mutator→tulis balik) |
| | `SchemaMigrations` | Definisi kanonik store→koleksi (`storeDefinitions()`) + migrasi berversi (`schema_migrations`, `LATEST`); nama tabel fisik `{store}_{koleksi}` (`tableName()`, mis. `apps_apps`, `auth_users`, `billing_users`, `billing_usage`, `billing_orders`, `backup_volumes`, `backup_registry`, `parked_domains`); nama kolom turunan dari dot-path (`.`→`_`) |
| | `JsonImporter` | Impor **sekali** `database/{apps,auth,billing,backup}.json` → SQLite (idempoten lewat flag `kv.legacy_imported_at`; store yang sudah berisi baris tidak ditimpa; berkas JSON lama **tidak** dihapus) + `exportToJson()` untuk rollback ke JSON |
| | `DbBackup` | Snapshot `VACUUM INTO` ke `{db_backup_dir}/rames-YYYYmmdd-HHMMSS.sqlite` + retensi harian/pekanan/bulanan (`keep_*`, pola `forget --keep-*`), mutex `flock` non-blocking (`<dir>/.lock`; busy → `skipped`), `restore()` defensif (basename+`realpath`, `integrity_check`, tabel inti `apps_apps`/`auth_users`/`billing_users`, safety snapshot `pre-restore-*`, ganti berkas atomik, `SqliteDatabase::reset()`), `isDue()`, `list()`/`download()`; `state.json` di `runtime/db-backup/` |
| | `JsonStore` | Baca/tulis **JSON cache runtime** (bukan data domain) dengan `flock` + salinan `<file>.bak`; `update()` atomik (tulis in-place, ownership file host terjaga). Dipakai `UpdateState` (check.json), state network Adminer, `BackupCatalog`/`BackupReport`, `DbBackup::state()` |
| | `AppStore` | CRUD entri app di **store `apps` (SQLite, §5.19)** + kepemilikan (`owner_id`, `members`): `addMember()`, `removeMember()`, `transferOwner()`, `transferAllFrom()`, `ownedBy()`, `assignMissingOwners()`; `path()` = path berkas `.sqlite` |
| | `AppFilter` | **Satu-satunya tempat pencocokan filter daftar app** (`?name=`/`?domain=`/`?owner=`, SPECS §8e): `apply()`/`matches()`/`normalize()`/`isActive()`; `domain` memakai domain efektif `app_subdomain_of()` atau `custom_domain`; `owner` cocok persis. **Statik murni** — tanpa I/O, tanpa state, **tanpa otorisasi** (pemanggil `AppController::index()` yang memutuskan filter mana yang berhak dihormati, mis. `owner` hanya admin); pengaman daftar tetap `AppAccess::visible()` |
| | `ServerStore` | Registry **server** (multi-server F0, §5.26): store logis `servers` di SQLite yang sama (tabel `servers_servers` — invarian `{store}_{tabel}`), API gaya `AppStore` (`all()`, `find()`, `findByName()`, `nameExists()`, `create()`, `update()`, `delete()`, `local()`); `ServerStore::LOCAL_ID = 'local'` = baris dashboard ini sendiri (di-seed migrasi v2, tidak bisa dihapus). `$filePath` di konstruktor = seam tes |
| | `ParkedDomainStore` | Store logis **`parked`** (tabel `parked_domains`, §5.38/SPECS §8j) — **metadata** domain parking; API gaya `AppStore` (`path()`, `all()`, `find()`, `byDomain()`, `domains()`, `create()`, `update()`, `delete()`). Id `pd_` + 12 hex; `all()` urut `domain` case-insensitive; keunikan `domain` ditegakkan di **dalam transaksi tulis** `SqliteStore::update()`. **Isi HTML tidak di sini** (berkas `database/parked/{id}/index.html`, `ParkedDomainContent`) |
| | `BrandingStore` | Store logis **`branding`** (tabel `branding_settings`, §5.40/SPECS §7.16) — satu dokumen `id=branding` `{name, logo, updated_at}`; `get()` **selalu** mengembalikan bentuk lengkap ternormalisasi (default `Rames`/`logo=null`, dokumen kosong/rusak ⇒ default), `save(name, logo)` hanya menerima **nama berkas** (`basename` + pola `logo.(png\|jpg\|jpeg\|webp)`, selain itu `null`), `reset()` menghapus dokumen (idempoten). `$filePath` di konstruktor = seam tes. Tanpa migrasi baru — tabel dibuat `SqliteStore::ensureSchema()` |
| **Auth** | `UserStore` | CRUD user di store `auth` (SQLite); hash bcrypt, `password_verify`; **verifikasi kredensial** `verify()` (login) & `verifyPassword()` (id + password → `bool`, `false` tanpa exception untuk id tak dikenal/hash kosong-legacy; dipakai ubah password self-service, §5.5a); **role global** `admin`/`member` (`roleOf()`, `isAdmin()`, `changeRole()`, `countAdmins()`, `listWithRoles()`) + migrasi lazy dokumen lama (user pertama = admin) |
| | `AppAccess` | **Satu-satunya pintu otorisasi app**: `roleFor()`, `can(ability, app, user)`, `require()` (melempar `AppAccessDenied`), `visible()` (filter daftar app), `abilitiesFor()`; stateless (aman untuk worker persistent). Ability `limits` (batas CPU/memori per service, §5.12a) eksklusif admin |
| | `AppAccessDenied` | Exception `extends BusinessException` yang merender **404** (JSON untuk `/api/*`, halaman 404 untuk request biasa) — menyembunyikan keberadaan app milik user lain |
| | `OwnershipMigrator` | Migrasi idempoten: app tanpa `owner_id` di-assign ke admin pertama |
| | `ServerAccess` | Otorisasi registry server (multi-server): **statik murni** (tanpa store/HTTP) — **dua kuasa terpisah**: (a) **kelola** registry **admin-only** (`canManageServers()`/`requireManageServers()` → `AppAccessDenied` = **404**); (b) **memilih** server = admin **atau** pemegang grant `server_select` (`hasServerSelectGrant()`, `canSelectServer()`, `serverAllowlist()`, `selectableServers()` = `local` selalu + allowlist/kosong = semua, `maySelect()` = satu pintu validasi id request). `visibleServers($servers, $user, $apps)`: admin → semua; non-admin → **union** server app yang lolos `AppAccess::visible()` + server grant (dedup, urutan registry) — grant **tidak** menambah ability `AppAccess`. Normalisasi flag/allowlist milik `UserStore` (tidak disalin); logika role tetap `AppAccess` |
| **Support** | `ProcessRunner` | Eksekusi command eksternal via `proc_open` (**array + `bypass_shell`** → tanpa shell, bebas command injection) + timeout; memasang `SIGCHLD=SIG_DFL` selama proses hidup agar git/docker compose tidak kehilangan `waitpid()` dan exit code tetap terbaca (§4.4). **`runStreaming($argv, …, $onChunk)`** meneruskan potongan stdout/stderr saat diterima (log build live); galat sink diabaikan agar proses tetap jalan |
| | `LogChunkReader` | Pembaca potongan berkas log berbasis offset (≤256 KiB per panggilan, dipangkas ke batas baris) — **satu implementasi** untuk log job agent (`AgentJobStore::readLog()`) dan log deploy (`DeployLog`); murni statik tanpa I/O state |
| | `SigchldGuard` | Penjaga disposisi `SIGCHLD` worker persistent: `disableIgnore()`, `withDefault()`, `ignoreAndReap()`, `isIgnored()`; murni statik, no-op bila pcntl tidak tersedia (§4.4) |
| | `DetachedWorker` | Spawn worker CLI **detached** (`pcntl_fork` + `posix_setsid` + `pcntl_exec`, **tanpa shell**) untuk aksi panjang dari request HTTP — dipakai `DeployWorkerLauncher` (semua op app) & `TemplatePullService` (§5.20); anak me-reset `SIGCHLD` ke `SIG_DFL` **sebelum** exec (pola `SigchldGuard`), induk `SIG_IGN` agar anak auto-reap. **Semantik env**: `spawn()` **selalu** menggabung lingkungan pemanggil dengan env tambahan (`$envp = array_merge(getenv() ?: [], array_map('strval', $env))`) karena `pcntl_exec` memakai `execve()` ⇒ argumen `envp` **menggantikan** seluruh lingkungan (array kosong = lingkungan kosong, **bukan** pewarisan; salah ⇒ worker kehilangan `RAMES_DB_DIR`/`RAMES_MODE`/`PATH`/`HOME` — GOTCHA §8 no. 39). `AppController::spawnWorker()` **hanya mendelegasikan** ke `DeployWorkerLauncher` (tak ada fork+exec di controller); sisa penyatuan tinggal `BackupController::spawnWorker()` (tech debt — GOTCHA §5.20) |
| | `Markdown` | Konversi **Markdown → HTML aman** untuk panduan template (§5.1c): `toHtml()` (statik murni, `html_input=escape` + `allow_unsafe_links=false` + `ExternalLinkExtension` → tautan eksternal `target="_blank"`/`rel="noopener noreferrer"`; converter juga mendaftarkan `TableExtension` → **tabel pipe GFM**, selain `CommonMarkCoreExtension` + `ExternalLinkExtension`); input kosong/whitespace **atau** kegagalan apa pun → `''` (panduan tak boleh menggagalkan halaman). Converter dibangun sekali (lazy static) |
| **Git** | `GitService` | `git clone --branch <branch> --depth=1 --single-branch` (**selalu shallow** — riwayat lokal 1 commit, satu branch; SHA lama diambil saat rollback via `fetch`) & `git pull --ff-only`; mendukung repo private via deploy key SSH (`GIT_SSH_COMMAND`) |
| | `SshKeyManager` | Generate/read/hapus pasangan kunci SSH (deploy key per app) di `database/keys/` |
| **Docker** | `ComposeParser` | Parse `docker-compose.yml` (short/long syntax port, IP binding) via `symfony/yaml` |
| | `ComposeDiscovery` | Penemuan project `docker compose` yang **sudah berjalan** di Engine host ini (§5.1d, SPECS §7.2c) — **read-only**, tanpa CLI compose & tanpa mutasi: `projects($apps)` (kelompokkan container berlabel `com.docker.compose.project`; project `rames`/`rames-agent` dikecualikan; nama yang sudah dipakai app **lokal** ditandai `conflict`/`importable=false`, bukan dibuang), `primaryChoices($row)` (`<service>:<portContainer>` untuk radio/select), `projectNamed()`, `validName()` (pola slug). Baris membawa `services`/`images`/`ports`/`running`/`state`/`working_dir`/`config_files` (absolut) dan `compose_files` (**basename**, metadata) |
| | `PortManager` | Deteksi konflik port terhadap `apps.json`, saran port dari range, validasi port |
| | `DockerClient` | Client Engine API (Guzzle + `CURLOPT_UNIX_SOCKET_PATH`): list/inspect container, **log container `containerLogs()` (`/containers/{id}/logs`, respons multiplexed)**, **monitoring `containersOverview()` (`/containers/{id}/stats` + `/json` untuk banyak container sekaligus — fan-out paralel `CurlMultiHandler`, karena satu `stats` butuh ±1 detik)**, list volume (per project / semua), **pemakaian disk `getDiskUsage()` (`/system/df`, sumber ukuran terpakai volume)**, list/inspect/buat network, connect/disconnect container ke network, hapus network, ping |
| | `ContainerLogs` | Pembersihan stream log multiplexed (`demultiplex()` — buang header 8 byte per frame; teks polos container TTY dikembalikan apa adanya) + normalisasi `tail` (`normalizeTail()`, `tailOptions()`); murni statik |
| | `AppContainers` | Resolusi container milik app: `resolve($app, $name)` (validasi nama — dipakai terminal, log, & file manager), `defaultContainer($app)` (container service `primary_service`, else pertama), dan **`fromEngineRows()`** — satu sumber pemetaan baris Engine → `{service_name, container_name, image, internal_port, host_port, ports[], status}` (dipakai `LocalDeployer::getContainers()` **dan** `ComposeImporter`, sehingga app impor tampil identik dengan app terkelola; dedupe port via `AppPorts::forContainer()`) |
| | `AppPorts` | Resolusi port app: `all($app)` (gabungan semua port publish tiap container), `forContainer($container)` (**dedupe** — Engine mengembalikan satu entri `Ports[]` per alamat IP untuk publish dual-stack IPv4+IPv6, plus fallback field lama `internal_port`/`host_port`), `proxiedContainerPort($app)` (port yang di-proxy Nginx — menghormati `primary_port`, fallback port pertama service primary), `primaryHostPort($app)` (target `proxy_pass`; dipakai `LocalDeployer` & view detail), **`hasHostPort($app)`** (penentu "app punya target `proxy_pass`": `false` ⇒ app tanpa vhost/subdomain, §5.1), `hostPortFor()`; murni statik tanpa I/O |
| | `VolumeUsage` | Pemetaan & format ukuran volume dari `GET /system/df` (`map()`, `summarize()`, `human()` — satuan SI seperti `docker system df`); murni statik tanpa I/O sehingga mudah diuji |
| | `ContainerStats` | Penafsiran `stats` + `inspect` menjadi baris monitoring (CPU% ala `docker stats`, memori dikurangi page cache cgroup, uptime dari `StartedAt`, restart count, health, PID) + `aggregate()` untuk total; murni statik tanpa I/O supaya rumusnya teruji |
| **Files** | `PathGuard` | Validasi & normalisasi path/nama file manager container — murni statik tanpa I/O (teruji tanpa Docker). `normalize()` (wajib absolut, selesaikan `.`/`..`, tolak keluar akar + karakter kontrol), `assertDeletable()` (tolak akar `/`), `assertName()` (tolak `/`/`\`, awalan `-`, `.`/`..`, > 255 byte), `resolveChild()`, `parentOf()`, `contains()`.
